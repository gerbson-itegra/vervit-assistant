# Documentacao Vervit

## Estrutura

- `_codebase/`: documentacao estrutural do sistema (STACK, ARCHITECTURE, CONVENTIONS, STRUCTURE, TESTING, INTEGRATIONS, CONCERNS).
- `<KEY>_issue.json`: dados da issue Jira.
- `<KEY>_PRD.md`: requisitos e criterios da tarefa.
- `<KEY>_TRACE.md`: decisoes, operacoes, testes e provedores.
- `<KEY>_state.json`: gates estruturados da tarefa.

Nunca registre credenciais, tokens, anexos ou dados binarios nestes arquivos.
