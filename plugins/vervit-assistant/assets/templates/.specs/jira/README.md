# Memoria Jira Vervit

Para cada atividade, `vervit-assistant-main` cria:

- `<KEY>/PRD.md`: requisitos e cenarios manuais aprovados.
- `<KEY>/TRACE.md`: decisoes, operacoes, testes, provedores e fallbacks.
- `<KEY>/state.json`: gates estruturados da tarefa.

Nunca registre credenciais, tokens, anexos ou dados binarios nesses arquivos.
