# Workflow Adaptativo

- Confirme `bug`, `feature` ou `improvement` e `hotfix` ou `planned`.
- Obtenha o fluxo com `python scripts/workflow_guard.py <tipo>`.
- Antes do código: branch correta, PRD aprovado, checklist publicado.
- Antes de integrar: trabalho preservado, testes/checklist completos, review aprovado e TRACE atualizado.
