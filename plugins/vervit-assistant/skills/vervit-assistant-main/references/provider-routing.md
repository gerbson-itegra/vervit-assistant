# Roteamento De Provedores

Carregue antes de delegar texto. Use `scripts/provider_router.py`.

Permitido: resumir/formatar fatos, release notes e resultados. Proibido: análise, decisões, PRD, plano, código, review, SemVer, Jira sensível e integração.

Respeite prioridade, `allowedTasks` e `jiraContentConsent`. Nunca envie credenciais, anexos ou binários. Registre provedor/fallback.
