# Releases Vervit

- `NEXT/`: unica release planejada ativa, com escopo aberto.
- `X.Y.Z/`: memoria congelada de uma release SemVer.
- Jira usa Fix Version `X.Y.Z`.
- Git usa tag anotada `vX.Y.Z`.

Uma release planejada so pode ser publicada depois de regressao geral, testes automatizados, release notes e sincronizacao entre `main` e `release`.
